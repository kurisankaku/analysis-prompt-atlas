これは何？

2つの数値が「一緒に増減するか」を −1〜+1 の1つの数字で表す指標。

たとえ：気温が上がるとアイスが売れる——のように「片方が増えると、もう片方も増える/減る」関係の強さを、+1（きれいに連動）〜 0（無関係）〜 −1（逆に連動）の目盛りで言い表したもの。

何が分かる？

2つの項目の連動の「向き（正・負）」と「強さ」が、ひと目で分かる。例えば「広告費」と「売上」の相関が +0.8 なら、広告費が増えるほど売上も増える傾向が強い、と言える。たくさんの項目の組み合わせを総当たりで見れば、どこに強い関係が潜んでいるかの当たりをつけられる。

どんなデータを用意する？

同じ対象について測った 2列以上の数値。1行が1件（1日・1人・1店舗など）に対応していること。

例：日別の広告費と売上（万円）

同じ「r」でも見え方は大違い。点の散らばりが強さを表す。
r ≈ 0.9　強い
r ≈ 0.1　ほぼ無関係

どんな時に使う／使わない方がいい時

✓ 使うべき場面

  • 2つの数値の連動を手早く確認したいとき
  • 多数の項目から関係の強い組合せの当たりをつけたいとき
  • 回帰分析などの前段の探索として

✕ 使わない方がいい場面

  • 曲線的な関係（U字など）を見たいとき
  • カテゴリ（性別・地域など）どうしの関係
  • 外れ値が数件混じっているとき

結果の読み方

目安：|r| が 0.7以上=強い／0.4〜0.7=中程度／0.2未満=ほぼ無関係。符号がプラスなら同じ方向、マイナスなら逆方向に動く。ただし「r=0.8だから広告が売上の原因」とは言えない（相関 ≠ 因果）。あくまで“一緒に動いている”という事実だけを表す。

使う前 → 後

使う前

広告費も売上も数字の列があるだけで、関係があるのか分からない。

使った後

「広告費と売上は強く連動（r≈0.85）」と一言で言え、次に回帰で“どれだけ効くか”を調べる方針が立つ。

注意点

相関は因果ではない。第3の要因（季節など）が両方を動かしているだけのこともある。
直線の関係しか測れない。曲線的な関係は r が低く出て見落とす。散布図を必ず併用。
外れ値に弱い。極端な数件で r が大きく変わることがある。

AIへの頼み方の一文例

Prompt example

「このデータで広告費と売上の相関係数を出し、関係の強さと向きを説明してください。散布図も描き、外れ値や曲線的な関係がないかも確認してください。相関だけでは因果は言えない点にも触れてください。」

参考：数式（補助）
r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √( Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)² )
